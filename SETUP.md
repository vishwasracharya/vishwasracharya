# Setup

1. Create or open the public GitHub repository named exactly:

   `vishwasracharya`

2. Copy `README.md` to the repository root.

3. Copy `.github/workflows/snake.yml` with the same folder structure.

4. Replace `YOUR_EMAIL_HERE` in `README.md`.

5. Commit and push the files to the `main` branch.

6. Open the repository's **Actions** tab and enable workflows if GitHub asks.

7. Run **Generate contribution snake** manually once using **Run workflow**.

8. After the workflow completes, refresh your GitHub profile.

## Notes

- The contribution snake is generated into an `output` branch.
- Some third-party stat cards can occasionally be rate-limited. The README still remains readable if a card is temporarily unavailable.
- Keep the repository public and ensure the repository name exactly matches your GitHub username.
